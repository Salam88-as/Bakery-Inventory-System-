# Bakery Inventory System

A web-based inventory management system for bakeries, built with ASP.NET MVC and C#. It helps keep track of products, stock levels, ingredients, and sales in one place.

## Features

- Add, edit, and delete products
- Track stock levels and see what is running low
- Manage ingredients used in baking
- Record and view sales
- Simple, easy-to-use web interface

## Tech Stack

- C#
- ASP.NET MVC
- SQL Server
- Entity Framework
- HTML, CSS, Bootstrap

## Getting Started

### Requirements

- Visual Studio 2019 or later
- .NET Framework 4.7.2 or later
- SQL Server (Express edition works fine)

### Setup

1. Clone the repository:

```
   git clone https://github.com/Salam88-as/Bakery-Inventory-System-.git
```

2. Open the solution file (`.sln`) in Visual Studio.
3. Open `Web.config` and update the connection string to match your SQL Server.
4. Restore NuGet packages (Right-click the solution, then **Restore NuGet Packages**).
5. Build the project and press **F5** to run it.

## Project Structure

```
Controllers/   Handles requests and application logic
Models/        Data models and database context
Views/         Pages shown to the user
Content/       CSS and images
Scripts/       JavaScript files
```
